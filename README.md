# Nexora Tech

Loja virtual front-end desenvolvida como projeto acadêmico.

A Nexora Tech é uma loja de tecnologia, periféricos e acessórios para setup, criada com foco em uma interface moderna, responsiva e organizada.

## Tecnologias

- HTML
- CSS
- JavaScript

## Objetivo

Criar uma loja virtual front-end responsiva para a atividade da faculdade, apresentando produtos de tecnologia em uma interface moderna, organizada e adaptável para computador e celular.

## Produtos

- Mouse gamer
- Teclado mecânico
- Headset
- Mousepad
- Webcam
- SSD
- Memória RAM
- Suporte para notebook
